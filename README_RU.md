# AccessoryHub — HTML, CSS, JavaScript и SQL

В проекте 3 страницы: `public/index.html` (главная), `public/register.html` (регистрация/вход), `public/success.html` (после регистрации). Пользователи хранятся в PostgreSQL. Сервер Node.js/Express соединяет сайт с базой; пароли сохраняются только в виде bcrypt-хэша.

## Пошаговая публикация

### 1. Создайте бесплатную PostgreSQL-базу
1. Откройте https://neon.tech/ и создайте аккаунт.
2. Создайте проект PostgreSQL.
3. В панели Neon откройте SQL Editor и выполните содержимое `schema.sql`.
4. Нажмите Connect и скопируйте connection string. Не публикуйте его.

### 2. Загрузите код на GitHub
1. На https://github.com/ создайте репозиторий, например `accessoryhub-sql`.
2. Загрузите содержимое этой папки, сохранив `public/`, `server.js`, `package.json`, `schema.sql`.
3. Не помещайте в публичный репозиторий пароль базы или JWT_SECRET.

### 3. Запустите сайт на Render
1. Откройте https://render.com/ и войдите через GitHub.
2. Нажмите New → Web Service и выберите репозиторий.
3. Build Command: `npm install`
4. Start Command: `npm start`
5. В Environment добавьте `DATABASE_URL` (строка подключения Neon) и `JWT_SECRET` (длинная случайная секретная строка).
6. Создайте Web Service и дождитесь запуска. Render даст ссылку `https://имя.onrender.com`.

Фронтенд и API запускаются на одном домене, поэтому дополнительных адресов в JavaScript менять не надо.

### 4. Проверка
Откройте ссылку Render → Регистрация / Вход → создайте пользователя → выйдите → войдите повторно. Для проверки таблицы выполните в Neon SQL Editor:
`SELECT id, name, email, created_at FROM users;`

## Важно
GitHub Pages публикует статические HTML/CSS/JS-файлы и не запускает сервер Node.js или SQL-базу. Поэтому для настоящей регистрации используйте Render + Neon, а GitHub — для хранения кода. Бесплатные тарифы могут иметь ограничения или усыплять сервис при простое; проверьте актуальные условия провайдеров. Для коммерческого использования стоит дополнительно реализовать восстановление пароля, подтверждение email и ограничение попыток входа.
